## ⚡ L'Applicazione

**Myrus** è un ambiente desktop open-source sviluppato da **Reflex Software** per la gestione avanzata e offline di siti web. 

Progettato con un'attenzione maniacale alla fluidità dell'interfaccia e all'esperienza utente (UX), Myrus permette di gestire i contenuti web in modo visivo, sicuro e immediato. Il software si interpone tra il layout originale e l'utente finale, consentendo la modifica rapida di testi, immagini e parametri strutturali senza alcuna manipolazione diretta del codice sorgente. 

L'obiettivo di Myrus è fornire un workflow locale, veloce e privo di distrazioni per il mantenimento di progetti web preesistenti.

## 🚀 Core Features

* **Gestione Visiva e Strutturale:** Sostituzione di testi e asset multimediali in totale sicurezza. Il motore di Myrus isola il codice, garantendo l'integrità del layout originale.
* **Viewport Integrato:** Ambiente di test e anteprima *Live* direttamente integrato nell'interfaccia, per verificare le modifiche in tempo reale su diverse risoluzioni.
* **Advanced SEO & Tracking Manager:** Interfaccia dedicata per l'iniezione sicura di meta-tag, descrizioni e snippet di tracciamento (Analytics, Pixel) nell'`<head>` dei progetti.
* **Workspace Multi-Sito:** Gestione centralizzata di innumerevoli progetti web da un'unica dashboard ottimizzata.
* **Smart Backup System:** Sistema di salvataggio preventivo. Ogni modifica genera automaticamente un punto di ripristino per garantire zero perdita di dati.
* **Ecosistema Dinamico:** Supporto nativo per i temi dell'interfaccia e un motore di aggiornamento (Auto-updater) silenzioso per ricevere le ultime patch senza interruzioni.

## 📥 Installazione e Avvio

Myrus è un'applicazione stand-alone e non richiede configurazioni di server locali o dipendenze complesse.

1. Scarica l'ultima release per il tuo sistema operativo dalla pagina **[Releases](https://github.com/Reflex-Software/myrus/releases)**.
2. Avvia l'installer.
3. Importa il tuo progetto web e inizia la gestione.

Essendo un progetto open-source, Myrus accoglie contributi dalla community. Se desideri implementare nuove funzionalità o ottimizzare l'engine, sentiti libero di fare il fork della repository e aprire una Pull Request.
